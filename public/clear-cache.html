🔧 Clear Cache & Fix Loading Issues

Having trouble loading data?

This page will help you clear all cached data and fix loading issues in Firefox and other browsers.

Quick Fix:

✅ Cache cleared successfully! Please refresh the page or go to home.

Manual Steps (if button doesn't work):

  • Firefox: Ctrl+Shift+Delete → Check "Cache" → Clear Now
  • Chrome: Ctrl+Shift+Delete → Check "Cached images and files" → Clear data
  • Safari: Cmd+Option+E → Empty Caches
  • Edge: Ctrl+Shift+Delete → Check "Cached images and files" → Clear now

What gets cleared:

  • Service Worker cache
  • Browser cache
  • Local storage (you'll need to log in again)
  • Session storage
